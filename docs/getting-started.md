# First integration

You do not need Discord or ads for the first test.

1. Register at [https://www.keyforge.win/register](https://www.keyforge.win/register).
2. Create a project and paste Luau. Pick protection and save.
3. Create one lifetime test key.
4. Copy the loader. Use [../integrations/keyforge-loader.lua](../integrations/keyforge-loader.lua) if you want `pcall` around `HttpGet`.
5. Confirm a handshake in Overview / analytics.

Then add HWID, Discord, or a reward link.

Starter is enough to prove the loader. Upgrade when you hit project, key, or obfuscation caps.

Live: [https://www.keyforge.win/docs](https://www.keyforge.win/docs)
