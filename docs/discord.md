# Discord integration

Discord is **optional** for the first loader test. Use it when buyers already live in your server.

Live: [https://www.keyforge.win/docs/discord-integration](https://www.keyforge.win/docs/discord-integration)

1. Invite the bot from Dashboard → Discord. Grant Manage Server so the bot can post and assign roles.
2. Run `/login` with the API key from the dashboard (server owner).
3. `/setrole` so a redeem grants a role.
4. `/panel` with your script id so members can get a key without you DMing strings.

You can reset HWID from Discord when the bot is linked, using the recovery commands your server is allowed to run.

Do not post keys in public chat instead of using the panel.

Use case: [https://www.keyforge.win/use-cases/discord-communities](https://www.keyforge.win/use-cases/discord-communities)
