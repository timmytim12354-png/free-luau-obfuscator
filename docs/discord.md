# Discord bot integration

Optional after the loader works. Checklist with no secrets: [../examples/discord-integration.md](../examples/discord-integration.md)

1. Invite the bot from Dashboard → Discord.
2. `/login` with the dashboard API key (owner). Never commit that key.
3. `/setrole` and `/panel`.

Live: [https://www.keyforge.win/docs/discord-integration](https://www.keyforge.win/docs/discord-integration)
