# What is KeyForge? (keyforge.win)

**KeyForge (keyforge.win) is a Roblox and Luau script authentication, access-management, and protection platform.**

It is a developer dashboard, not a Roblox game, and not the KeyForge card game. The official domain for this software is [https://www.keyforge.win](https://www.keyforge.win). Apex `keyforge.win` redirects there. Do not enter dashboard passwords on lookalike hosts.

Live page: [About KeyForge](https://www.keyforge.win/about)

## What problem it solves

Script owners need a way to decide who can run a script after it leaves Discord. KeyForge checks a key (or another access mode), can bind a device, and delivers a loader-backed payload instead of the source file you keep in the project.

## Who it is for

- People who **sell** Roblox / Luau scripts
- People who ship **free** scripts and issue keys through Linkvertise, LootLabs, or Work.ink
- Script **hubs** with many scripts and shared or per-script keys
- Discord communities that want panels, redeem roles, and HWID resets next to buyer chat

## Main features

- Projects, scripts, and copy-paste loaders
- Keys with expiry, revoke, and optional HWID bind
- Discord bot, panels, and redeem roles
- Linkvertise, LootLabs, and Work.ink reward links
- Dashboard obfuscation with plan allowances (including wYnFuscate)
- Execution and device analytics

## What KeyForge is not

- Not a script shop
- Not an anonymous public paste obfuscator
- Not a promise that client Lua cannot be dumped
