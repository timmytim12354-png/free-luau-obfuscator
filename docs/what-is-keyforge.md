# What KeyForge is

**KeyForge (keyforge.win)** is a Roblox and Luau script authentication, access-management, and protection platform. It is a developer dashboard, not a Roblox game, and not the KeyForge card game. Official domain: [https://www.keyforge.win](https://www.keyforge.win).

You store a script, issue keys (or Discord / reward-link / keyless access), and users run a loader. KeyForge authenticates on the server and can bind HWID after first use.
