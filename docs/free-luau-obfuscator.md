# Free Luau / wYnFuscate obfuscator for Roblox scripts

KeyForge includes dashboard obfuscation so the file you deliver is not the file you edit. Starter includes a published **wYnFuscate** allowance. Pair it with a [Roblox key system](roblox-key-system.md) — obfuscation alone is not a license.

Live page: [Free Luau obfuscator workflow](https://www.keyforge.win/free-luau-obfuscator)

## What ships today

In the dashboard you pick a protection method when you save a script. KeyForge can obfuscate on save and serve the cached build from the loader. Plan pages on [keyforge.win](https://www.keyforge.win) list monthly wYnFuscate counts for Starter, Basic, and Creator; Scale and Enterprise lift those caps.

The [standalone /obfuscator](https://www.keyforge.win/obfuscator) ForgeVM lab is a separate tool and is **not publicly enabled by default**. Do not treat that URL as a free anonymous obfuscator.

## Recommended workflow

1. Create a project and paste your Luau.
2. Choose protection / obfuscation and save so a cached build exists.
3. Generate a test key and enable HWID if you need device lock.
4. Copy the loader — not the source — into Discord or your script hub.
5. Confirm a run in analytics, then issue buyer keys or an ad-link gate.

## Should I only obfuscate and skip keys?

No. Obfuscation slows casual reading. A key system plus HWID is what actually withdraws access. See [script protection](script-protection.md).
