# KeyForge FAQ

**What is KeyForge?**  
KeyForge (keyforge.win) is a Roblox and Luau script authentication, access-management, and protection platform. It is not the KeyForge card game.

**Is there a free Roblox key system?**  
Yes. Starter is free with published limits. [keyforge.win/roblox-key-system](https://www.keyforge.win/roblox-key-system)

**Is there a free Luau obfuscator?**  
Starter includes a published wYnFuscate allowance. The `/obfuscator` lab is admin-gated and is not a public paste tool. [keyforge.win/free-luau-obfuscator](https://www.keyforge.win/free-luau-obfuscator)

**Should I only obfuscate?**  
No. Obfuscation slows reading. Keys + HWID withdraw access.

**Where is the SDK?**  
Download [https://www.keyforge.win/sdk/client.lua](https://www.keyforge.win/sdk/client.lua). Docs: [custom-lua-gui-sdk.md](custom-lua-gui-sdk.md)

**Does a hidden loader URL protect my script?**  
No. See [how-the-loader-works.md](how-the-loader-works.md)

**Can I use Linkvertise / LootLabs / Work.ink?**  
Yes. [monetization.md](monetization.md)

**Will this stop every dumper?**  
No honest host can promise that.
