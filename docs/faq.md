# FAQ

**What is KeyForge?**  
KeyForge (keyforge.win) is a Roblox and Luau script authentication, access-management, and protection platform. Not the card game.

**Does this repo obfuscate my script?**  
`cli/` minifies or formats locally. Hosted wYnFuscate runs in the dashboard. See [hosted-obfuscation.md](hosted-obfuscation.md).

**Where is the SDK?**  
`https://www.keyforge.win/sdk/client.lua` — fetch it, do not vendor it. [custom-lua-gui-sdk.md](custom-lua-gui-sdk.md)

**How do I authenticate from Luau?**  
[using-keyforge-auth-from-luau.md](using-keyforge-auth-from-luau.md)

**Can I build a custom key UI?**  
Creator / Scale / Enterprise. [custom-key-system-ui-roblox.md](custom-key-system-ui-roblox.md)

**Will this stop every dumper?**  
No honest host can promise that.
