# Monetize Roblox script access

KeyForge does not replace Stripe or your storefront. It issues the license after someone pays you or finishes a reward link.

Live: [https://www.keyforge.win/docs/monetization](https://www.keyforge.win/docs/monetization)

## Paid scripts

Generate keys after checkout (manually or via your own automation). Map Discord roles if you sell in-server. See [paid scripts use case](https://www.keyforge.win/use-cases/paid-scripts).

## Reward links (free scripts)

Dashboard → Ad links. Paste a real **Linkvertise**, **LootLabs**, or **Work.ink** URL. Set the return URL to your `/a/…` gate. Complete the checkpoint yourself before you post the link publicly.

Do not paste a LootLabs locker id into a Linkvertise field.

Starter reward links include a KeyForge platform ad per claim. Paid plans remove that extra ad. See homepage pricing.

## Webhooks

Dashboard webhooks notify a URL you control. HTTPS only, not localhost. Treat the URL like a secret. Tester: [https://www.keyforge.win/tools/webhook-tester](https://www.keyforge.win/tools/webhook-tester)
