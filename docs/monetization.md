# Reward links and webhooks

KeyForge issues the license after someone pays you or finishes a checkpoint. It does not replace Stripe.

**Paid scripts:** generate keys after checkout. Map Discord roles if you sell in-server.

**Reward links:** Dashboard → Ad links. Paste a real Linkvertise, LootLabs, or Work.ink URL. Set the return URL to your `/a/…` gate. Complete the checkpoint yourself before you post it. Do not paste a LootLabs locker id into a Linkvertise field.

Custom UI Get Key: [../examples/reward-link-example.lua](../examples/reward-link-example.lua)

Starter reward pages include a KeyForge platform ad per claim. Paid plans remove that extra ad. Confirm on the homepage.

**Webhooks:** HTTPS URL you control, not localhost. Tester: [https://www.keyforge.win/tools/webhook-tester](https://www.keyforge.win/tools/webhook-tester)

Live: [https://www.keyforge.win/docs/monetization](https://www.keyforge.win/docs/monetization)
