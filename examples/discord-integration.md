# Discord integration (owner checklist)

Discord is optional for the first loader test. Use it when buyers already live in your server.

1. Dashboard → Discord → invite the bot (Manage Server).
2. Run `/login` with the API key from the dashboard (server owner). Do not paste that key in this repo or in public chat.
3. `/setrole` so a redeem grants a role.
4. `/panel` with your script id.

Reset HWID from the bot only when your server policy allows it. Prefer the panel over posting keys in a channel.

Live steps: [https://www.keyforge.win/docs/discord-integration](https://www.keyforge.win/docs/discord-integration)
